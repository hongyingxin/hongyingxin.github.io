### 1. esbuild 和 Terser 压缩能力对比

结论：Terser 的压缩能力更强，但是 esbuild 的构建速度更快。

Terser 提供了 AST 优化能力，能够更深入、更可配置，但同时牺牲了速度。

需要注意的是：Vite7 官方已经使用 Oxc 作为默认压缩器。

### 2. Brotli 和 Gzip 压缩能力对比

结论：Brotli 压缩率比 Gzip 高 15%～25%，但压缩速度更慢，同时无法兼容旧浏览器。

## 10月9日

### 1. script 标签为什么归属于宏任务

今天在复习的时候，突然看到之前写着“script 标签归属于宏任务队列”，但是感觉不对，因为 script 标签是同步执行的，应该归属于同步任务。

这里其实是因为混淆了两个不同的概念：

1. 同步任务/异步任务：描述代码如何执行
2. 宏任务/微任务：描述任务在事件循环 Event Loop 中的调度方式

同步任务和宏任务并不是互斥的概念。
同步任务描述代码的执行方式，而宏任务描述事件循环的调度单位。
浏览器执行初始 script 时，可以将其理解为执行一个宏任务，其中的普通 JavaScript 代码仍然是同步执行的。
当同步代码执行完毕，调用栈清空后，事件循环会执行微任务检查点，处理 Promise 等微任务，然后再继续处理后续任务。

总结：宏任务是调度单位，同步代码是执行方式。一个宏任务内部可以包含大量同步代码。
